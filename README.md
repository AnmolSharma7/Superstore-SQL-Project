# Superstore-SQL-Project

## Project Overview
This project analyzes retail sales data using MySQL.
The dataset was imported from a CSV file and analyzed using SQL queries to identify sales trends, top customers, and profitable products.

---

## Objectives
- Analyze retail sales performance
- Identify top customers and profitable products
- Perform data cleaning and validation
- Generate business insights using SQL

---

## Tools Used
- MySQL
- MySQL Workbench
- Excel
- CSV Dataset

---

## Dataset Information
Customized Superstore dataset containing sales-related information such as:
- Sales
- Profit
- Category
- Customer Name
- Order Date
- Product Name

---

## SQL Concepts Used
- SELECT
- GROUP BY
- ORDER BY
- Aggregate Functions
- LIMIT
- Date Functions
- Data Cleaning
- Duplicate Checks
- Null Value Checks

---

## Key Analysis Performed

### 1. Total Sales Analysis
Calculated overall sales generated from the dataset.

### 2. Total Profit Analysis
Calculated overall profit.

### 3. Top Customers Analysis
Identified customers with highest purchases.

### 4. Category-wise Sales Analysis
Compared sales across product categories.

### 5. Monthly Sales Trend Analysis
Analyzed monthly sales trends using date functions.

### 6. Duplicate Check
Checked dataset for duplicate records.

### 7. Null Value Check
Validated data quality by checking null values.

---

## Key Insights
- Technology category generated high sales.
- Top customers contributed major revenue.
- Monthly sales trends showed variations across months.
- Dataset contained clean and structured data after validation.
